# 清洗

对所选目录中的旁路 `*.txt` 做规范化与重组（不递归子目录）。可先预览再写入。

## 界面

1. 勾选目录，填写：整词删除、子串删除、提升至头部、头部前置。
2. 可选：**写入 Pony 美学档位**、**以 `|||` 分隔头部与正文**。
3. 先预览对比样本，确认后再写入（覆盖原文件）。

## 处理顺序（摘要）

HTML 还原 → 拆分 tag → 下划线转空格 → 删除（含内置 commentary / request）→ 提升 → 可选美学 `score_N` → 头部前置 → 可选 `|||` 分隔。

美学档位来自同 stem 图像在 `.aesthetic_scores.json` 中的分数；无分则该文件不注入。
