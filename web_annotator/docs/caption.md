# 描述

对所选目录的图片调用 Ollama 视觉模型生成自然语言描述，写入各工作目录的
`captions.json`，供 diffusion-pipe 直接作为目录级 caption 使用。

## 界面

1. 勾选目录，点击 **开始标注** 打开 **描述设置** 对话框：里面集中了描述模式、注入设置、
   提示词补充与「覆盖已有描述」，在对话框底部再点 **开始标注** 提交。
2. 提交后对话框关闭，工具栏显示任务进度与 **取消**；卡片绿色边框表示已有描述，
   点击卡片可查看该图片的描述全文。
3. 状态栏给出 `共 / 已描述 / 未描述` 张数；侧栏目录列表实时反映标注进度。

## 输出格式

描述写入图片所在目录的 `captions.json`：

```json
{
  "0001.png": [
    "1girl, black hair, ...",
    "1girl, black hair, ... 详细描述"
  ]
}
```

- 键为**图片文件名**（不含目录），值为描述列表，顺序为所选模式的顺序
  （粗略 → 详细）。
- diffusion-pipe 只要目录内存在 `captions.json` 即按其内容取 caption，并忽略同名的
  `.txt`；同一图片的多条描述会各自展开为一条训练样本（即该图被复制 N 次参与训练）。
- **不要开启** `online_captions`：该开关改从图片绝对路径取 caption，与上述文件名键
  不匹配，会退化为空 caption。

## 描述模式

| 模式 | 说明 |
| --- | --- |
| 粗略 | 只描述画面焦点与要点，用密集英文表达 |
| 详细 | 详细描述全部实体的属性、关系与空间排布 |

## WD14 参考标签

- 打标页执行 WD14 打标时，阈值（默认 0.1）以上的标签、置信度与标签类型会缓存到
  `<数据集根>/.wd14_meta/<子目录>/<图片名>.json`。
- 描述页在 **描述设置** 对话框里配置注入：**标签范围** 取通用标签、角色标签或两者，
  **置信度 ≥** 只注入缓存中置信度不低于该值的标签；候选交给模型核对画面后取舍。
- **缓存缺失的图片，提交描述任务时先跑 WD14 补建缓存**（只写 `.wd14_meta`，不生成同名
  `.txt`）；缓存齐备时不加载 WD14 模型。补建所用推理阈值取 WD14 默认值与本次注入下限中
  更低者，故缓存既不比默认更严，也不会丢掉本次可注入的标签。只对本次实际待描述的图片
  补建（已在 `captions.json` 中且未勾选「覆盖」的图片跳过）；单张补建失败记入日志后继续。
- 注入内容按标签类型分行并带上置信度，例如：

  ```
  来自 WD14 的 Danbooru 通用标签可供参考: "1girl":0.98, "black hair":0.52
  来自 WD14 的 Danbooru 角色标签可供参考: "typhoeus (arknights)":0.98
  ```

## 描述设置

点击工具栏 **开始标注** 打开「描述设置」对话框；以下设置保存在浏览器本地并与当前数据集
绑定（该说明写在对话框标题栏右侧）。

- **生成设置**：一行一项参数。
  - **描述模式**：粗略 / 详细 可多选，写入 `captions.json` 时按此顺序排列。
  - **WD14 参考标签**：通用标签与角色标签各自勾选并各自设置置信度下限（见上节）。
  - **已有描述**：勾选「覆盖」时重新标注已有描述的图片并覆盖其 `captions.json` 条目。
- **提示词补充**：分 **新增区** 与 **条目表** 两块。
  - 新增区选择模板后 **模板句式原样显示，其中的 `{{ 字段 }}` 空位即内联待填输入框**，
    填好后点 **添加** 生成一条条目；选「自定义（无模板）」则添加空条目，内容在条目表里填。
  - 条目表表头两列：**匹配标签 / 提示词内容**。「匹配标签」填图片的 WD14 缓存标签需命中的
    模式（支持 `*` 通配，逗号分隔多个模式）才注入；留空则对该数据集全部图片生效。
    命中判定同样依赖 WD14 缓存，缓存缺失时按上节规则先补建。生成后的文本仍可手工编辑。

  模板只收带变量的句式，触发标签与空位取值都由你设置：

  | 模板 | 句式空位 |
  |------|----------|
  | 角色数据集 | 角色名、主角特征 |
  | 画风数据集 | 艺术家名 |
  | 概念数据集 | 概念名 |
  | 负面偏见标注 | 偏见项 |
  | 角色特征触发词 | 触发词、特征说明 |

用户提示词为逐行拼接，不加分节标题与列表符号：先命中的预设提示词文本（每条一行），
再 WD14 参考标签行。

## 服务配置

描述服务取 `.env` 的 `CAPTION_OLLAMA_ENDPOINTS`：逗号分隔的 `地址|模型` 对，地址含
协议与端口（如 `http://10.0.0.1:11434|qwen3-vl:8b`）；未配置或格式错误时描述页不可用。

| 变量 | 说明 |
| --- | --- |
| `CAPTION_OLLAMA_ENDPOINTS` | 描述服务列表；每项为 `地址|模型`，多个服务时图片在服务间并行分发 |
| `CAPTION_NUM_CTX` | 上下文长度；留空为 `0`，即不传 `num_ctx`，由服务端默认值决定 |
| `CAPTION_NUM_PREDICT` | 单张生成的最大 token 数；留空为 `8192`，`0` 表示不传 `num_predict` |
| `CAPTION_TIMEOUT` | 单张生成超时（秒）；留空为 `60` |

每个服务对应一个工作线程，从共享队列取图（先空闲先领），同一服务同一时刻只有一张在
生成；全部服务均连通且已安装目标模型时才可提交任务。图片原样发送文件字节，不做缩放、
透明通道合成或重编码。单张生成失败会重新排队重试至多 3 次；流式输出出现周期性重复时
按失败处理。

服务地址为内网地址时不受 `.env` 中 `HTTP_PROXY` / `HTTPS_PROXY` 影响（请求显式关闭
环境代理）。
