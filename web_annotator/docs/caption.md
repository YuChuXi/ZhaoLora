# 描述

对所选目录的图片调用 OpenAI 兼容视觉模型生成自然语言描述，写入各工作目录的
`captions.json`，供 diffusion-pipe 直接作为目录级 caption 使用。

## 界面

1. 勾选目录，点击 **开始标注** 打开 **描述设置** 对话框：里面集中了描述模式、注入设置、
   提示词补充与「清空已有描述」，在对话框底部再点 **开始标注** 提交。
2. 提交后对话框关闭，工具栏显示任务进度与 **取消**；卡片绿色边框表示已有描述，
   点击卡片可查看该图片的描述全文，并可在查看窗口中删除该图片的描述。
3. 状态栏给出 `共 / 已描述 / 未描述` 张数；侧栏目录列表实时反映标注进度。

## 描述筛选

瀑布流上方的筛选栏按描述文本过滤图片，留空显示全部；任一模式命中即保留该图片：

- **严格子串**：描述原文包含输入串（区分大小写）。
- **Danbooru 通配(*)**：小写并把下划线视作空格后，按 `*` 通配做整串匹配。
- **正则**：对描述原文做正则搜索。

「预置」下拉提供内置条件，默认项「拒绝话术」：定位含
`i can't` / `i cannot` / `i won't` / `unable to` / `i'm sorry` / `i apologize` /
`refuse` / `as an ai language model` / `against my guidelines` / `illegal` 等拒绝话术
的描述，用于清理被模型拒答污染的标注。该正则忽略大小写（`(?i)` 内联标志由前端转为
`i` 标志），并兼容直引号与弯引号撇号。筛选为前端执行，不改变 `captions.json`。

## 输出格式

描述写入图片所在目录的 `captions.json`：

```json
{
  "0001.png": [
    "1girl, black hair, ...",
    "1girl, black hair, ... 详细描述"
  ]
}
```

- 键为**图片文件名**（不含目录），值为描述列表，顺序为所选模式的顺序
  （粗略 → 详细）。
- diffusion-pipe 在目录内存在 `captions.json` 时默认按其内容取 caption，并忽略同名的
  `.txt`；同一图片的多条描述会各自展开为一条训练样本（即该图被复制 N 次参与训练）。
  要改用同名 `.txt` 标注，在 `dataset.toml` 顶层或对应 `[[directory]]` 中设
  `use_captions_json = false`。
- **不要开启** `online_captions`：该开关改从图片绝对路径取 caption，与上述文件名键
  不匹配，会退化为空 caption。

## 描述模式

| 模式 | 说明 |
| --- | --- |
| 粗略 | 只描述画面焦点与要点，用密集英文表达 |
| 详细 | 详细描述全部实体的属性、关系与空间排布 |

## WD14 参考标签

- 打标页执行 WD14 打标时，模型输出的**完整概率向量**（含 rating 分级）缓存到
  `<数据集根>/.wd14_meta/<模型指纹>/<子目录>/<图片stem>.npy`；阈值调整无需重新推理。
  模型指纹取权重与标签表同名 CSV 的内容哈希前 16 位，模型或标签表变化即换缓存目录；
  指纹本身缓存在任务根 `.wd14_model.json`，避免每次启动重读权重。
- 描述页在 **描述设置** 对话框里配置注入：**标签范围** 取通用标签、角色标签或两者，
  **置信度 ≥** 只注入缓存中置信度不低于该值的标签；候选交给模型核对画面后取舍。
- **缓存缺失的图片，提交描述任务时先跑 WD14 补建缓存**（只写 `.wd14_meta`，不生成同名
  `.txt`）；缓存齐备时不加载 WD14 模型。补建所用推理阈值取 WD14 默认值与本次注入下限中
  更低者，故缓存既不比默认更严，也不会丢掉本次可用的标签。只对本次实际待描述的图片
  补建（已在 `captions.json` 中且未勾选「清空」的图片跳过）；单张补建失败记入日志后继续。
- 注入内容按标签类型分行并带上置信度，例如：

  ```
  来自 WD14 的 Danbooru 通用标签可供参考: "1girl":0.98, "black hair":0.52
  来自 WD14 的 Danbooru 角色标签可供参考: "typhoeus (arknights)":0.98
  ```

## NSFW 增强

- 勾选 **启用** 后，逐图检查 WD14 缓存 rating 分级中 **Explicit** 或 **Questionable**
  的置信度：任一不低于设定阈值时，在预设提示词之后追加一行备注
  `Using explicit slang.`，引导模型用直白俚语描述画面；同时在系统提示词头部注入
  `assets/purge.txt` 补丁（空行分隔），模式模板接在补丁之后。
- 阈值与参考标签注入共用同一套缓存：rating 分级取自整条概率向量，改阈值无需重新推理；
  启用后缓存缺失的图片同样先补建缓存。

## 描述设置

点击工具栏 **开始标注** 打开「描述设置」对话框；以下设置随其他页面的输入参数一并
持久化到任务目录根下的 `.annotator_settings.json`（按数据集区分）。

- **生成设置**：一行一项参数。
  - **描述模式**：粗略 / 详细 可多选，写入 `captions.json` 时按此顺序排列。
  - **WD14 参考标签**：通用标签与角色标签各自勾选并各自设置置信度下限（见上节）。
  - **NSFW 增强**：勾选并设置置信度下限，Explicit 或 Questionable 达标时追加备注
    并在系统提示词头部注入补丁（见上节）。
  - **已有描述**：勾选「清空」时先清空所选目录的全部已有描述，再重新标注全部图片；
    未勾选时跳过已有描述的图片。
- **提示词补充**：分 **新增区** 与 **条目表** 两块。
  - 新增区选择模板后 **模板句式原样显示，其中的 `{{ 字段 }}` 空位即内联待填输入框**，
    填好后点 **添加** 生成一条条目；选「自定义（无模板）」则添加空条目，内容在条目表里填。
  - 条目表表头两列：**匹配标签 / 提示词内容**。「匹配标签」填图片的 WD14 缓存标签需命中的
    模式（支持 `*` 通配，逗号分隔多个模式）才注入；留空则对该数据集全部图片生效。
    命中判定同样依赖 WD14 缓存，缓存缺失时按上节规则先补建。生成后的文本仍可手工编辑。

  模板只收带变量的句式，触发标签与空位取值都由你设置：

  | 模板 | 句式空位 |
  |------|----------|
  | 角色数据集 | 角色名、主角特征 |
  | 画风数据集 | 艺术家名 |
  | 概念数据集 | 概念名 |
  | 负面偏见标注 | 偏见项 |
  | 角色特征触发词 | 触发词、特征说明 |

用户提示词为逐行拼接，不加分节标题与列表符号：先命中的预设提示词文本（每条一行，
NSFW 增强命中时在末尾追加 `Using explicit slang.` 行），再 WD14 参考标签行。

## 服务配置

描述服务取 `.env` 的 `CAPTION_OPENAI_BASE_URL`（OpenAI 兼容 API 根地址，含 `/v1`）
与 `CAPTION_OPENAI_MODEL`；二者任一为空时描述页不可用。`CAPTION_OPENAI_API_KEY`
留空时不发送 `Authorization` 头。

| 变量 | 说明 |
| --- | --- |
| `CAPTION_OPENAI_BASE_URL` | 服务根地址，如 `http://10.0.0.1:8000/v1` |
| `CAPTION_OPENAI_MODEL` | 视觉模型名 |
| `CAPTION_OPENAI_API_KEY` | 服务密钥；留空免认证 |
| `CAPTION_CONCURRENCY` | 同时处理的图片数；留空为 `1` |
| `CAPTION_OPENAI_EXTRA_BODY` | JSON 对象，原样合并进请求体；用于传递思考开关与等级等扩展字段 |
| `CAPTION_OPENAI_HEADERS` | JSON 对象，与默认 UA、`Authorization` 合并；用于覆盖 UA 或传服务端要求的会话标识 |
| `CAPTION_MAX_TOKENS` | 单张生成的最大 token 数；留空为 `8192`，`0` 表示不传 `max_tokens` |
| `CAPTION_TIMEOUT` | 单张生成超时（秒）；留空为 `60` |

思考控制由服务端方言决定，统一经 `CAPTION_OPENAI_EXTRA_BODY` 透传：DeepSeek 关闭思考写
`{"thinking": {"type": "disabled"}}`，OpenAI 写 `{"reasoning_effort": "low"}`；留空时
使用服务端默认值。思考片段不写入描述。

`CAPTION_CONCURRENCY` 个工作协程从共享队列取图（先空闲先领）；服务连通且已提供目标
模型时才可提交任务。图片以 data URL 内联发送原始文件字节，不做缩放、透明通道合成或
重编码。单张生成失败会重新排队重试至多 3 次。

请求遵循 `.env` 中的 `HTTP_PROXY` / `HTTPS_PROXY`；服务地址为内网时须将其加入
`NO_PROXY`，避免被代理拦截。
