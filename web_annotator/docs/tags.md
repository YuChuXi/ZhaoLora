# 标签

本页包含：**频率统计**、**批量翻译**与对话框 **自动生成（WD14）**。

## 频率统计

1. 右上角勾选含旁路 `.txt` 的目录。
2. 调整是否忽略大小写、下划线等同、按样本去重等选项后查看频率表。
3. 勾选标签行，可复制英文或中文汇总。

## 批量翻译

1. 点 **翻译缺失** 将当前表格中缺少中文的标签批量提交 Google 翻译。
2. 翻译结果写入 `datasets/.translation_cache.json`，跨数据集共享。
3. 翻译完成后自动刷新表格，中文列即时更新。

## 自动生成（WD14）

1. 点 **自动生成** 打开对话框。
2. 确认模型就绪后设置置信度、是否忽略已有标签、是否覆盖已有 `.txt`。
3. **开始** 后进度条仅在排队 / 运行中显示；关闭对话框不中断任务。流程分两阶段：
   先为缺失缓存的图片推理并缓存整条概率向量，再统一按阈值取标签写出 `{stem}.txt`。
4. 输出为 Anima 格式：头部按 性别 → 角色 → 画师 收纳，`|||` 分隔通用标签正文；
   rating 分级不写入。

模型输出的完整概率向量缓存到 `<数据集根>/.wd14_meta/<模型指纹>/<子目录>/<stem>.npy`：
模型指纹由权重与标签表 CSV 的内容哈希决定，模型或标签表更换后旧缓存自动失效，阈值
调整无需重新推理。模型权重经 `.env` 的 `WD14_MODEL` 指向 `.onnx` 文件，标签表取与其
同名的 `.csv`；留空时使用仓库内默认模型。未就绪时不可开始。
