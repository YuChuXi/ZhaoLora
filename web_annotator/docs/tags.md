# 标签

本页包含：**频率统计**与对话框 **自动生成（WD14）**。

## 频率统计

1. 右上角勾选含旁路 `.txt` 的目录。
2. 调整是否忽略大小写、下划线等同、按样本去重等选项后查看频率表。
3. 勾选标签行，可复制英文或中文汇总（中文来自本机翻译缓存，无则占位）。

## 自动生成（WD14）

1. 点 **自动生成** 打开对话框。
2. 确认模型就绪后设置置信度、是否忽略已有标签、是否覆盖已有 `.txt`。
3. **开始** 后进度条仅在排队 / 运行中显示；关闭对话框不中断任务。
4. 可为每张图写出旁路 `{stem}.txt`（按置信度排序，过滤 rating 类）。

模型目录需放置在仓库约定位置（`wd14_tagger_model/...`）；未就绪时不可开始。
