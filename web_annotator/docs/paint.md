# 蒙版

在 `main/` 源图上绘制 Alpha，写入 `mask/`（与源图同相对路径的 `.png`）。

## 界面

- 顶栏：翻页、跳过、保存、全透明 / 全不透明 / 恢复默认、笔刷、左键擦除、默认 Alpha、保存格式。
- 底栏：序号、已标注数量、文件名、已标注/待标注、分辨率、缓冲信息。
- 列表优先展示尚无蒙版的图像。

## 绘制

| 操作 | 效果 |
|------|------|
| 左键 | 默认擦除（alpha=0）；可关闭「左键擦除」改为涂满 |
| 右键 | 涂不透明 |
| 笔刷 | 相对图像对角线百分比；滚轮微调 |
| 全透明 / 全不透明 | 整幅重置 |

## 保存策略

- 上一张 / 下一张：自动保存（未改且已有蒙版则跳过；尚无蒙版时会写出默认 Alpha）。
- **跳过**：不保存。
- **S / 保存**：显式保存。

## 快捷键

| 键 | 行为 |
|----|------|
| ← / A · → / D | 上一张 / 下一张 |
| S | 保存 |
| X | 跳过 |

## 蒙版生成

顶栏「生成蒙版」打开对话框，支持两种生成方式，均支持**当前图**（默认）与**批量**（勾选「批量处理整个目录」；「跳过已有蒙版」仅在批量模式生效）：

- **BiRefNet 背景移除**：自动抠取主体，可配置扩展 / 收缩像素与蒙版值域（最小 / 最大值）。
- **SAM3 概念分割**：按蒙板表达式计算蒙版。表达式运算全程在 0-1 域进行，遵循标准优先级（`*` 高于 `+`/`-`，比较最低，括号最高），运算符包括 `+`（钳位相加）/ `-`（钳位相减）/ `*`（0-1 域相乘）/ `min(a,b)` / `max(a,b)` / `blur(掩码,半径)`（高斯模糊，半径单位为像素，用于平滑概念边缘）/ 比较 `>` `<` `>=` `<=` `==` `!=`，与括号组合操作数；`当前蒙板` 为当前已保存的蒙版（不存在时视为全不透明 255），`"概念文本"` 为 SAM3 分割提示词（支持 ASCII 与中文全角引号），数值字面量按 0-1 书写（支持任意实数，×255 为蒙板值）。示例：

  ```
  (当前蒙板-("白色背景"+"对话气泡"))
  ```

  表示从当前蒙板中减去白色背景与对话气泡相加的区域。

生成任务通过顶部进度条实时显示，完成后保持当前图片位置并就地更新蒙版显示。

## 与就绪页

就绪导出仅在 main 蒙版状态为 **完整**（每张 main 图都有对应蒙版）时，才为 main 写入 `conditioning_data_dir`。
