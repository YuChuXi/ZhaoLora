# 就绪

根据当前任务工作目录生成训练用 TOML 文本，供复制到训练配置。本页不写磁盘。

## 界面

- **顶栏**：生成、复制、`num_repeats`、subset 数量。
- **左侧栏**：工作目录表格（目录、张数、蒙版完整/无状态）。
- 主区为 TOML 预览。

## 蒙版状态（仅两种）

| 状态 | 含义 |
|------|------|
| 完整 | `main/` 中每张图在 `mask/` 下都有对应蒙版 |
| 无 | 尚有缺蒙版的图（含一张都没有） |

仅当整体为 **完整** 时，main subset 才附带 `conditioning_data_dir`。其它部位目录只有 `image_dir` 与 `num_repeats`。

## 生成规则

1. `main` 优先，其余按名称排序；无图像目录跳过。
2. 修改蒙版或目录后需重新生成再复制。
