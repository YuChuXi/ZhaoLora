# 裁剪

仅处理 `main/` 中的源图。多选区吸附训练分辨率桶，输出到部位目录或 `crops/`。

## 界面

- 顶栏：上一张 / 下一张 / 跳过 / 保存、新建选区、清空、整图输出、部位名。
- 侧栏：选区列表、添加自动部位、**默认裁切**（保存在本机，按任务与部位）。
- 底栏分段：序号、已裁数量、文件名、已裁剪/未裁剪、分辨率、选区与自动部位说明。

## 默认裁切

侧栏「默认裁切」格式：`宽x高@缩放`，例如 `1536x1536@1.0`。

- 空键（全局）：无部位名时新建选区使用。
- 部位名：该部位新建选区使用；未填则回退全局。

不再依赖启动参数指定默认裁切。

## 吸附网格

边长 512–3072、步长 128；缩放 `1 / 1.5 / 2 / 2.5 / 3 / 4`；最大输出约 `1536×1536` 像素。

## 快捷键

| 键 | 行为 |
|----|------|
| S / Ctrl+S | 保存 |
| 空格 / → / Ctrl+N | 跳到下一张未裁 |
| ← | 上一张 |
| A | 新建选区 |
| D / Delete | 删除当前选区 |
| C | 清空选区 |
