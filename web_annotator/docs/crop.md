# 裁剪

从任意工作目录选取源图。多选区吸附训练分辨率桶，输出到部位目录或 `crops/`。

## 界面

- 导航栏右上角：目录选择器（全站统一组件，单选，main 置顶）。
- 顶栏：上一张 / 下一张 / 跳过 / 保存、新建选区、清空、整图输出、部位名。
- 侧栏：选区列表、添加自动部位、**默认裁切**（保存在本机，按任务与部位）。
- 底栏分段：序号、已裁数量、文件名、已裁剪/未裁剪、分辨率、选区与自动部位说明。

## 源目录

导航栏右上角的目录选择器选择参与裁剪的工作目录（数据集根下一级子目录，单选；与蒙版页同款组件），选择按任务保存在本机。源图路径为数据集根相对路径（如 `gpt/foo.png`）。

## 输出规则

- 部位名即输出目录名：命名选区写 `root/{部位名}/`，未命名选区写 `root/crops/`；整图输出必须填写部位名。
- 输出目录不得为 `main`、`mask`、`crops` 等保留名，也不得与当前源目录相同（防止裁剪结果与源图混写）。
- 部位候选（侧栏自动部位与部位目录列表）排除 `video` 目录与当前源目录；`video` 是切帧来源的工作目录，不参与部位输出。
- 输出文件名为 `{stem}.png`，同名输出直接覆盖；一轮内同名输出自动追加序号。
- 完成标记按文件名 stem 全局判定（任一部位目录或 `crops/` 已有同 stem 输出即视为已裁剪；当前源目录自身除外）。

## 默认裁切

侧栏「默认裁切」格式：`宽x高@缩放`，例如 `1536x1536@1.0`。

- 空键（全局）：无部位名时新建选区使用。
- 部位名：该部位新建选区使用；未填则回退全局。

不再依赖启动参数指定默认裁切。

## 吸附网格

边长 512–3072、步长 128；缩放 `1 / 1.5 / 2 / 2.5 / 3 / 4`；最大输出约 `1536×1536` 像素。

## 快捷键

| 键 | 行为 |
|----|------|
| S / Ctrl+S | 保存 |
| 空格 / → / D / Ctrl+N | 跳到下一张未裁 |
| ← / A | 上一张 |
| Q | 新建选区 |
| E / Delete | 删除当前选区 |
| C | 清空选区 |
