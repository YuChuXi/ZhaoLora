# 美学与评分项

评分页包含两类评分：美学模型评分与基于 WD14 标签概率的评分项。

## 美学评分

对所选工作目录中的图像打美学分（CLIP ViT-L/14 + 美学头）。

1. 右上角勾选要评分的子目录。
2. 选择 **美学** 标签页，点 **开始**；底栏显示任务态与进度。
3. 可随时 **取消**。结果写入 `.aesthetic_scores.json`，并按 `score_0`…`score_9` 分档展示。

## 评分项

评分项是 WD14 标签概率的表达式，每个数据集可自定义，用于评分页展示与筛选页排序。

- 表达式中的双引号字符串引用同名 WD14 标签概率，例如 `"loli"`。
- 语法与蒙板表达式一致：算术（`+ - *`）、比较与 `min` / `max` / `sum` / `avg` /
  `abs` / `sqrt` / `exp` / `log` / `pow` / `clamp` / `blur` 函数。
- 内置项不可删除：
  - **CSAM**：`max("loli", "shota")`
  - **NSFW**：`max("sensitive" * 0.33, "questionable" * 0.66, "explicit")`
- 顶栏 **评分项** 打开管理对话框：查看内置项、添加自定义项（名称 + 表达式）、删除自定义项。
  添加时会校验表达式语法与引用标签是否存在于 WD14 标签表。

### 建立 WD14 缓存

评分项只读取 WD14 推理缓存，不重新推理。首次使用或新增图片后：

1. 勾选要处理的工作目录。
2. 点 **建立缓存**；任务为缺失的图片逐张推理并把整条概率向量写入
   `<图片目录>/.wd14_meta/<模型指纹>/<stem>.npy`。
3. 缓存就绪后在任一评分项标签页点 **开始**，按缓存概率计算全部评分项。

缓存缺失的图片在计算时计入跳过，底栏消息会提示先建立缓存。

## 结果写到哪里

- `.aesthetic_scores.json`：美学原始分
- `.score_results.json`：各评分项 `{相对路径: 分数}`，按评分项 key 分组
- `.annotator_scoring.json`：自定义评分项定义（内置项不入文件）

## 与其它页的关系

- **筛选**：排序下拉会列出全部评分项，卡片前缀显示各评分项分值。
- **清洗**：可选把美学分映射为 `score_0`…`score_9` 写入标签头部。
