# 美学

对所选工作目录中的图像打美学分，并在本页查看报告。

## 界面

1. 右上角勾选要评分的子目录。
2. 选择设备（CPU / CUDA；不可用时 CUDA 选项禁用）。
3. 点 **开始**；底栏显示任务态与进度；进度条仅在排队或运行中出现。
4. 可随时 **取消**。完成后报告嵌入本页；也可从任务卡片看到「有美学报告」。

## 结果写到哪里

- `.aesthetic_scores.json`：每张图的原始分  
- `aesthetic_report.html`：可浏览的报告  

## 与其它页的关系

- **筛选**：可按美学分排序与展示。  
- **清洗**：可选把分数映射为 `score_0`…`score_9` 写入标签头部。
