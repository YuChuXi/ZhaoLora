# 标签检查

瀑布流检查所选目录中每张图片旁路 `*.txt` 是否包含指定标签，以及标签是否在期望位置。

## 界面

1. 勾选目录，输入标签，选择期望位置，点击 **检查**。
2. 卡片边框含义：
   - **绿色** — 标签存在且位置符合。
   - **红色** — 标签缺失或位置不符。
3. **点击任意卡片** — 自动在对应位置添加标签（先去重再插入），完成后卡片转为绿色。

## 应用蒙板显示

勾选工具栏 **蒙板** 开关后，瀑布流每张图片与其已保存蒙板合成（去背），
透明区显示棋盘格背景，便于直观检查蒙板质量；无蒙板的图片保持原图。再次勾选可随时切换。

## 位置选项

| 选项 | 含义 | 点击添加时的插入位置 |
| --- | --- | --- |
| 任意位置 | 标签存在于 caption 中即可 | 头部末尾 |
| 置顶（首位） | 标签位于整个 caption 的第一位 | 头部首位 |
| 置底（末位） | 标签位于整个 caption 的最后一位 | 有 `|||` 时正文末尾，否则头部末尾 |
| 在 `|||` 前 | 标签位于头部（`|||` 之前） | 头部末尾 |
| 在 `|||` 后 | 标签位于正文（`|||` 之后） | 正文首位（无 `|||` 时自动创建） |

标签比较忽略大小写与下划线差异（`1girl` 与 `1_Girl` 视为同一标签）。

## 相似度排序与批量标记

点击工具栏 **相似度** 按钮打开对话框，基于 Qwen3-VL-Reranker-2B 对 (查询文本, 图片)
配对实时评分（cross-encoder，不预计算缓存）。

1. **按相似度排序**：输入查询文本后排序，对所选目录全部图片逐张评分，
   以异步长任务执行并由 SSE 推送进度；完成后瀑布流按相似度降序重排，卡片前缀 `S`
   显示相似度（经 sigmoid 映射到 [0, 1]）。
2. **批量标记**：按工具栏预设的标签与位置，以相似度阈值批量处理：
   - 关系为「≥ 阈值」时**添加**标签至匹配图片；
   - 关系为「≤ 阈值」时**删除**标签，删除支持模糊匹配（子串匹配）。

| 键 | 行为 |

| ← / A · → / D | 上一张 / 下一张 |
| Esc | 返回瀑布流 |
