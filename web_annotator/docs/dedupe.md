# 去重

路径：`/dedupe`

对所选工作目录中的图像做低分辨率指纹比对，按组展示重复项，批量移入回收站。

## 算法概要

1. 将图像缩放到 **128×128** RGB，计算指纹。
2. 组内两两比较 MSE；低于阈值则视为相似。
3. 跨所选目录的图像**合并后统一比对**（不仅限单目录内）。
4. 损坏或无法解码的图像跳过。

支持扩展名相对筛选更窄（不含部分格式如 bmp/gif，以服务端 `IMAGE_EXTS` 为准）。

## 参数（UI 默认）

| 参数 | 默认 | 约束 | 含义 |
|------|------|------|------|
| MSE 阈值 | `0.0001` | `(0, 1]` | 越小越严格 |
| 分辨率比 | `1.05` | `≥ 1` | 判定「分辨率接近」的比值上限 |

## 建议保留策略

对每组选出建议保留项，其余为 `suggested_remove`：

1. 若组内分辨率比 ≤ `similar_res_ratio`：优先 **JPEG blockiness 更低**（更清晰），再比面积，再比文件名。
2. 否则：优先 **面积更大**，再比文件名。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/dedupe/dirs` | 可扫描目录 |
| POST | `/api/dedupe/scan` | `{ dirs, mse_threshold, similar_res_ratio }` → `groups` |
| POST | `/api/dedupe/apply` | `{ paths, dirs }`：校验仍存活后调用与筛选相同的删除逻辑 |

## UI 行为

1. 扫描完成后，各组默认勾选 `suggested_remove`。
2. 「仅留建议」/「套用建议」/「清空选择」调整勾选。
3. 左键切换选中；右键打开灯箱（缩略图 → 原图）。
4. 应用删除后，前端本地更新组；成员不足 2 的组移除。

## 灯箱快捷键

仅预览打开时有效：

| 键 | 行为 |
|----|------|
| Esc | 关闭 |
| ← / → | 切换组内图片 |
| Space / Enter | 切换当前项选中 |

## 文件系统

与筛选共用 `.annotator_state.json` 与 `.trash/`。删除规则（含同 stem 旁路文件）一致。
