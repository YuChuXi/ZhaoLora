# 去重

对所选工作目录中的图像做相似分组，勾选后移入回收站。

## 界面

1. 右上角勾选目录，调整 **MSE 阈值** 与 **分辨率比**（越小越严）。
2. **扫描** 得到分组；默认勾选「建议删除」项。
3. **建议删除** 按算法重新勾选；**全不选** 只清勾选，保留分组结果。
4. 左键切换勾选；右键打开预览。确认后 **删除** 进回收站。

## 建议保留策略（简述）

组内分辨率接近时优先更清晰者；否则优先更大图。其余进入建议删除。

## 预览快捷键

| 键 | 行为 |
|----|------|
| ← / → | 组内切换 |
| Esc | 关闭预览 |
