# 筛选

瀑布流浏览与挑选样本；支持本地目录与 Gelbooru / Danbooru。

## 本地模式

1. 「来源」选 **本地**，右上角勾选工作目录。
2. 单击选中 / 取消；顶栏 **已收录 / 已选择 / 回收站**。
3. **删除** 将选中项移入回收站；**恢复** 可整库或按选中恢复。
4. 右键可找色调相似图。

### 快捷键（本地）

| 键 | 行为 |
|----|------|
| Delete | 删除选中 |
| A | 全选 |
| D | 取消全选 |

## 远程模式（Gelbooru / Danbooru）

1. 「来源」选图站，输入标签，设置条件与页码后 **搜索**。
2. 左键触发 **下载** 并写入当前工作子目录；完成后状态为 **已保存**。
3. 顶栏 **已收录**（工作目录磁盘张数）· **已加载**（当前搜索结果）。点选即写入，无「已选择」。
4. 「条件」角标统计全部已生效项（评级、分数/宽高/ID 上下限、日期、用户、附加元标签）；悬停可看摘要。
5. 对已保存条目可 **移除**（从工作目录删去对应文件）；移除后「已收录」会刷新。
6. 更改列数后会尽量回到原先浏览的页位。

远程产物（每个帖子）：图像、旁路 `.txt`、以及对应的元数据目录。

## 代理

若直连失败，启动时配置 `--booru-proxy`；界面也可勾选「代理图」经本机拉取预览。
